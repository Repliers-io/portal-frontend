# Listings

Everything under `/api/listings` is served by `src/routes/listings.ts`. Every route uses
passthrough auth (`middleware.jwt.passthrough`): a guest with no token is allowed, a valid
token makes the request a user, and an invalid token is a 401. Guest responses are
[scrubbed](/architecture/scrubbing); [restricted listings](/architecture/restricted-listings)
are removed at the exits listed in its [enforcement register](/architecture/restricted-listings#enforcement-register). Terms are defined in the [Glossary](/glossary).

This page is the operation index. The summary table carries each endpoint's auth, caching,
side effects and error statuses; the mechanisms, parameters and rationale are on the deep
pages, and the full parameter contract is in Swagger (`/swagger`).

response cache header the handler writes; "none" means no `Cache-Control`.

## Route order

`@koa/router` matches in registration order, so the declaration order in
`src/routes/listings.ts` decides which handler a path reaches:

- `search`, `count`, `locations`, `nlp`, `lastUpdatedOn`, `featured/{slug}` and `history` are
  all declared before the parametric `/{mlsNumber}`, which would otherwise match them as an MLS
  number.
- `/{mlsNumber}/similar` is declared before `/featured/{slug}`, so
  `GET /api/listings/featured/similar` reaches the similar handler with `mlsNumber = "featured"`,
  not the featured handler.

## Behavioral notes

The behaviour that used to be listed here now lives with its mechanism:

- **Search filters, status vocabularies, aggregates, `queries[]`, repeated values, the identity
  fields added to `fields` / `clusterFields`** → [Search & Count](/api-reference/listings/search).
- **Single availability and the 410, similar, cross-board history, and the event-selector
  callers that reach `RepliersListings.single` directly** →
  [Detail, Similar & History](/api-reference/listings/detail-similar-history).
- **NLP, featured, locations and the synthetic `lastUpdatedOn`** →
  [NLP, Featured & Misc](/api-reference/listings/nlp-featured-locations).
