# Environment Variables

Every `AppConfig` value is backed by an env var with a default, and a preset can
override the env-built value (see [Configuration Resolution](/architecture/configuration-resolution)).
Four variables have no usable default and the process asserts them at start:
`REPLIERS_API_KEY`, `MAPBOX_ACCESS_TOKEN`, `JWT_PRIVATE_KEY`, `JWT_PUBLIC_KEY` ([startup prerequisites](/architecture/configuration-resolution#startup-prerequisites)). Grouped by
prefix; defaults shown where they matter. The authoritative list lives in the repository
README and `src/config.ts`. Secrets belong in the process environment only
([Deployment](/operations/deployment#environment-specifics)).
