## Minimal incident record

Record the trigger, expected versus observed outcome, sanitized request/response,
owning source symbol, the observation that disproved the first hypothesis, and the
verification after correction. Separate a source-derived explanation from a
runtime observation. Application changes discovered during documentation work
need their own agreed scope.
