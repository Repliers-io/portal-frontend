# Shared Components

> API reference for the reusable building blocks under `src/components/shared/`,
> `src/components/atoms/` and `src/components/templates/` — the parts a new page or a
> tenant fork composes instead of rebuilding. Placement rules live in
> [Architecture](/technical-guide/architecture#components-structure).

<Callout type="info">
  Last audited against `master` on **2026-09-29** (covers everything added or
  changed since the July 2026 docs rework). When you add a shared component or a
  prop, add its row here; the next audit starts from this date.
</Callout>

Before building a new UI piece, search here and in `components/shared/` first — a
component that "looks almost right" is meant to be reused and restyled in a tenant fork,
not copied.

## Map chrome (`@shared/Map`)

| Export                           | What it is                                                                                                                                                                                                                                   | Props / API                                                                                                                                                                                                                                                                                              |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MapControlsStack`               | The absolutely-positioned column the map buttons live in. A top-anchored stack clears the `MapTitle` bar only while the bar is visible (`useMapTitleVisible`).                                                                               | `position?`, `mobilePosition?` (`ControlsPosition`, default from `@configs/map` `controls`), `sx?`. Also exports `controlSize` (36) and `borderMargin` (16) — the numbers every piece of map chrome aligns to.                                                                                           |
| `MapControlButton`               | One button of the stack, tooltip on the left. Colours come from `@configs/map` `controls.colors`.                                                                                                                                            | `title` (tooltip + accessible name), `active?`, `dimmed?` (on but drawing nothing — below the layer's render floor), `activeBg?` (a control's own active fill, e.g. an overlay accent), `loading?` (dot over the icon while data loads), `desktopOnly?` (hidden below `sm`), plus any MUI `ButtonProps`. |
| `mapControlSx`                   | The same chrome as an `sx` object, for a control that can't be a `MapControlButton` (e.g. a menu trigger).                                                                                                                                   | `({ active?, dimmed?, activeBg? })`                                                                                                                                                                                                                                                                      |
| `MapLocateButton`                | GPS "locate me": drops the address point pin at the device position and flies there (same `setPoint` + `flyTo` as picking an address). Hides itself once geolocation permission is denied.                                                   | none                                                                                                                                                                                                                                                                                                     |
| `MapNavigation` · `MapStyleMenu` | Zoom pair and base-style menu.                                                                                                                                                                                                               | `disabled?` — e.g. while the map is still loading.                                                                                                                                                                                                                                                       |
| `SelectedLocations`              | The selected locations as removable chips (moved out of `MapTitle/components`). Chip body recenters the map, the X removes that location.                                                                                                    | `locations`, `wrap?` (chips run onto further rows).                                                                                                                                                                                                                                                      |
| `SelectedLocationsBar`           | Mobile stand-in for the `MapTitle` bar: the same chips along the bottom edge, clearing the controls stack. Renders only below `sm` and only with a selection.                                                                                | none                                                                                                                                                                                                                                                                                                     |
| `HomeMap`                        | Single-property map (PDP, buildings, location headers, parcel dialog).                                                                                                                                                                       | New: `bounds?` (initial viewport, nothing drawn), `boundsPadding?` (px around `bounds`/`boundary`, default 10). `marker` is optional — omit it and no marker is drawn.                                                                                                                                   |
| `OverlayLocationButton`          | Touch-only "Show listings here" / "Remove this location" action inside an overlay tooltip card — the tap counterpart of a desktop marker click. Renders nothing unless the tooltip was tap-opened and the overlay is selectable on this map. | none — tooltip cards place it where they want it.                                                                                                                                                                                                                                                        |

### Marker element (`markerElement.ts`)

- `markerKind(size, price?)` — a `tag`-size marker gets a price pill only for a positive
  price; `0` / scrubbed collapses to a dot, so no marker ever reads "$0".
- `createMarkerElement({ …, hitArea })` — `hitArea: true` adds a transparent 44×44 tap
  target under the shape, active on coarse pointers only (overlay markers set it).
- `setMarkerHover(root, hover)` / `markerHover(mlsNumber)` — lets something other than
  the marker (the parcel under it) drive the marker's hover; resolves multi-unit
  markers through `data-members`.

### Map hooks (`@shared/Map/hooks`)

| Hook                                                     | Does                                                                                                                                                                                                                                                           |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useMapTitleVisible()`                                   | `true` while the `MapTitle` bar shows (a title, a selected location, or a point).                                                                                                                                                                              |
| `useOverlayPolygonGuard()`                               | Keeps a search polygon and _selectable_ overlays mutually exclusive: when a polygon appears (drawn or from the URL) it switches those overlays off. One-way.                                                                                                   |
| `usePoint()`                                             | The search point: a radius-less point as a Signpost pin (click recenters), a point with a radius as a static circle through the shared polygon renderer.                                                                                                       |
| `useMapListener(mapRef, attach)` · `useMapReady(mapRef)` | `mapRef.current` is assigned without a re-render. `useMapListener` attaches listeners once the map exists; `useMapReady` is a flag that flips true then — the dependency for effects that need the map. Use these instead of polling `mapRef.current` by hand. |
| `useOverlayLocationToggle(overlays)`                     | Toggles an overlay feature's location in the selection — shared by marker clicks and `OverlayLocationButton`.                                                                                                                                                  |
| `useParcelGroups()` · `useParcelListings()`              | Parcels mode — see [Map Overlays](/technical-guide/map-overlays#parcels-mode).                                                                                                                                                                                 |

## Forms (`@shared/Forms`)

Which fields are required is **tenant config**, not code: `@configs/forms` lists
`required` fields and `requiredAny` groups (at least one member filled, e.g.
`[['email', 'phone']]`), globally or per form key (`contact`, `requestInfo`, `tour`,
`meeting`, `jobApplication`, `subscribe`). A form key under `forms` replaces the global
rules for that form; a tenant that declares `forms` replaces the whole map.

| Export                                                  | What it is                                                                                                                          | Props / API                                                                                                                                                                     |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `resolveRequirements(form, fields)`                     | Config rules narrowed to the fields a form actually renders. A group with one rendered member becomes a plain required field.       | returns `ResolvedRequirements` `{ required, groups }`                                                                                                                           |
| `FormRequirements`                                      | Context provider for the resolved rules; wrap the fields in it.                                                                     | `requirements`, `children`                                                                                                                                                      |
| `FormField`                                             | react-hook-form `Controller` + `TextField` + label. Asterisk from the requirements context; group members show none.                | `name` (a `FormFieldName`), `control`, `label?`, `containerSx?`, `formatter?(value, previous)`, plus `TextFieldProps`                                                           |
| `FieldWrapper`                                          | Caption label (+ `*`) above any control. Moved up from `ContactForm/`.                                                              | `label?`, `required?`, `containerSx?`                                                                                                                                           |
| `RequiredAnyHint`                                       | The single "email or phone" message under an unmet `requiredAny` group.                                                             | `control`                                                                                                                                                                       |
| `withGroupCheck(resolver, groups, message)`             | Wraps a Joi resolver with the "at least one of" check (Joi's `.or()` can't report on a field).                                      | —                                                                                                                                                                               |
| `ContactForm`                                           | Inline contact form.                                                                                                                | New: `mlsNumber?` (posts a property enquiry instead of a general comment), `tags?` (FUB lead tags, forwarded as-is), `labels?` (captions above fields instead of placeholders). |
| `ContactFormFields`                                     | The name / email+phone / message field set, for a caller that owns the `<form>` (e.g. a dialog with the submit in `DialogActions`). | `control`, `showMessage?`, `labels?`, `variant?`                                                                                                                                |
| `useContactForm(options)`                               | Form state + submit for the above.                                                                                                  | New: `tags?`, `form?` (config key; defaults to `requestInfo` with an `mlsNumber`, else `contact`). Returns `requirements` for `FormRequirements`.                               |
| `useScheduleForm({ form, send, onSend })` · `DateField` | Name/email/phone + date + time forms (PDP tour, estimate meeting). The caller owns the payload via `send`.                          | `DateField`: `name` (`'date'` \| `'time'`), `control`, `label`                                                                                                                  |
| `LegalText`                                             | Consent/legal line under a submit. The default renders nothing — it's a tenant fork slot.                                           | `centered?`, `variant?`, `action?`                                                                                                                                              |

Field formats (length caps, phone validity per `@configs/i18n` `phoneNumberLocale`,
future-only dates) live in `fieldSchemas.ts` and apply to every form.

`useContactForm` and `useScheduleForm` share `useRequirementsForm` (internal): config
requirements → Joi resolver with the group check → `useForm`, plus clearing a `requiredAny`
group's error from every member once one member is filled. A new lead-form hook builds on
it rather than wiring the resolver again.

## Listing cards & galleries

| Component                        | Change                                                                                                                                                                                                                                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ListingCard` → `Tags`           | Inside a `CardSurface`, the status badge follows `@configs/badgeSurfaces` (which statuses badge on `map`, `search`, `carousel`, `locations`, `favorites`, `recent`, `gallery`).
