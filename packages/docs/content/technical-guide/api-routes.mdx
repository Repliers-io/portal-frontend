# Frontend Route Handlers

Source review: `e30dd9b47`, 2026-11-02. These are Next.js handlers inside the
frontend, **not** the proxy backend's `/api` contract. A relative browser request
to `/api/schools` reaches this application; `APISearch` reaches
`NEXT_PUBLIC_API_URL + /api/listings/search`. See [API Services](/technical-guide/api-services).

## Shared boundary

`src/app/api/_lib.ts` provides `assertSameOrigin`, `parseQuery`, `parseBody` and
`getClientIp`. `assertSameOrigin` checks whether the Referer starts with the
configured application domain; an unset domain disables this check. It is not a
JWT or resource-ownership check. Only handlers that call it get that behavior.
Joi parsing returns validation errors; each handler still owns its upstream and
failure response. Do not infer a common error envelope from the `/api` prefix.

The endpoint-specific absence of a guard is a description of the current code,
not permission to expose arbitrary new inputs. New handlers should reuse the
nearest equivalent contract, including the `map` polygon format. External values
entering URL path segments require an explicit allowlist before interpolation.

## Revalidation contract

POST accepts a JSON object with `path` and `token`. The path must start with `/`,
exclude `..`, match the handler's safe-character expression and fit its 300-character
limit. The handler expands the input against `rewrites.generated.json` in both
source-to-destination and destination-to-source directions, then calls
`revalidatePath` for the deduplicated paths. A success response records invalidation;
it does not prove fresh upstream content has rendered. See
[Caching and Revalidation](/technical-guide/caching-and-revalidation).

## Other route handlers

The other **six** `route.ts` files publish crawl surfaces: `robots.txt`,
`sitemap.xml`, `sitemap-content.xml`, `listing/sitemap-index.xml`,
`listing/sitemap/[id]`, and `documentation/sitemap/[site]`. They belong to
[SEO](/technical-guide/seo), not the interactive JSON API. The six metadata
`sitemap.ts` files are separate from this 29-file handler inventory.

## Evidence and limits

This register was reconciled against handler exports and shared helpers. It is
source evidence, not an HTTP replay of each integration. Credentials, deployment
URLs and tenant records are intentionally absent. Mutation endpoints were not
called while writing documentation.
