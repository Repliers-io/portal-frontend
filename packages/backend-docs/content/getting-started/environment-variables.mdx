# Environment Variables

Every `AppConfig` value is backed by an env var with a working default — the app
starts with an empty `.env`. Grouped by prefix; defaults shown where they matter.
The authoritative list lives in the repository README and `src/config.ts`.

## Application (`APP_`)

| Variable | Default | Purpose |
|---|---|---|
| `APP_SETTINGS_PRESET` | — | Settings preset name (see [Configuration Model](/getting-started/configuration)) |
| `APP_CORS_DOMAIN` | `http://localhost:3000` | Allowed CORS origins |
| `APP_DEFAULTS_BOARDIDS` | `110` | Comma-separated default boardIds |
| `APP_DISABLE_PERSISTENCE` | `false` | Disable Postgres-backed features |
| `APP_LOCATIONS_BOARDID` | `110` | Default boardId for `/locations` |
| `APP_ALLOWED_LISTINGS_STANDARD_STATUSES` | — | RESO Standard Statuses available to the frontend |
| `APP_HIDE_UNAVAILABLE_LISTINGS_STATUSES` | — | Statuses hidden from the frontend |
| `APP_HIDE_UNAVAILABLE_LISTINGS_STANDARD_STATUSES` | — | RESO variant of the above |
| `APP_HIDE_UNAVAILABLE_LISTINGS_HTTP_CODE` | `410` | Status code served for hidden listings |
| `APP_STATSTOP_LIMIT` | `100` | Top-N limit for stats/neighborhoods ranking |
| `APP_USESWAGGER` | `false` | Serve the Swagger UI at `/swagger` |
| `APP_LOGGING_GCP_LOGGER_ENABLED` | `false` | Google Cloud logging |

## Authentication (`AUTH_`, `JWT_`)

## Repliers API (`REPLIERS_`)

| Variable | Default | Purpose |
|---|---|---|
| `REPLIERS_API_KEY` | — | **Required.** Free sample-data keys at login.repliers.com |
| `REPLIERS_API_KEY_EXTRA` | — | Second key for the historical listings behind estimate property details |
| `REPLIERS_BASE_URL` | `https://api.repliers.io` | Upstream base URL |
| `REPLIERS_TIMEOUT` | `30000` | Response timeout |
| `REPLIERS_API_LIMIT` / `REPLIERS_API_INTERVAL_MS` | `1` / `1000` | Request throttle (N per interval) |
| `REPLIERS_CACHE_WARMUP_API_KEY` | — | Separate key for SSG traffic; off when unset (see [SSG cache-warmup key](/architecture/repliers-proxy#ssg-cache-warmup-key)) |
| `REPLIERS_CACHE_WARMUP_API_LIMIT` / `REPLIERS_CACHE_WARMUP_API_INTERVAL_MS` | `REPLIERS_API_LIMIT` / `REPLIERS_API_INTERVAL_MS` | The warmup key's own throttle |
| `REPLIERS_AGENT_ID` | `0` | agentId for Repliers calls |
| `REPLIERS_AGENT_EMAIL` | — | Agent email for custom SMTP |
| `REPLIERS_PROXY_XFF` | `false` | Forward client IPs to Repliers |
| `XFF_SSR_TOKEN` | — | Shared secret identifying SSR requests (`X-Forwarded-For-Token`); legacy alias `REPLIERS_PROXY_XFF_SSR_TOKEN` |
| `XFF_SSG_TOKEN` | — | Shared secret for requests with no user behind them (build, ISR, warm-up) — skips IP forwarding, selects the warmup key; legacy alias `REPLIERS_PROXY_XFF_SSG_TOKEN` |
| `XFF_SSR_IPADDR_OFFSET` | `2` | Position of the real client IP in the `X-Forwarded-For` chain; legacy alias `REPLIERS_PROXY_XFF_SSR_IPADDR_OFFSET` |
| `REPLIERS_ESTIMATES_SEND_EMAIL_NOW` | `false` | Send estimate email immediately |
| `REPLIERS_ESTIMATES_SEND_EMAIL_MONTHLY` | `false` | Monthly estimate emails |
| `REPLIERS_AUTOSUGGEST_*` | — | Autosuggest listing-search tuning: `PROVIDER` (`mapbox`/`googlemaps`), `MAX_RESULTS`, `MAX_RESULTS_DEFAULT`, `LISTING_STATUS`, `LISTING_LAST_STATUS`, `LISTING_STANDARD_STATUS` (RESO instances — replaces the two above), `LISTING_TYPE`, `SEARCH_FIELDS`, `DISPLAY_PUBLIC_VALUE` |
